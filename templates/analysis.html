2. Model Training Module

Three models were trained using the same 80/20 train-test split:

  • Model 1: Linear Regression - Baseline linear model
  • Model 2: Random Forest - Ensemble method with 100 trees, max_depth=10
  • Model 3: Gradient Boosting - Sequential ensemble with 100 estimators, max_depth=5

Training Split: 80% training, 20% testing

Random State: 42 (for reproducibility)

3. Model Evaluation

Each model was evaluated using three standard regression metrics:

  • RMSE (Root Mean Squared Error): Measures the average magnitude of errors (lower is better)
  • MAE (Mean Absolute Error): Average absolute difference between predicted and actual values (lower is better)
  • R² Score (Coefficient of Determination): Proportion of variance explained by the model (higher is better, range: 0-1)

5. Best Model Selection Logic

Selected Model: {{ data.best_model_name }}

Selection Criteria

The best model was automatically selected based on a combined scoring approach:

  • Lowest RMSE: Minimizes prediction errors
  • Lowest MAE: Reduces average absolute deviation
  • Highest R² Score: Maximizes variance explained

Combined Score Formula: RMSE + MAE - R² (lower is better)

Why Automatic Selection?

Avoids Bias: Automatic selection eliminates human bias and subjective judgment, ensuring an objective, data-driven decision.

Scientific Soundness: This approach is scientifically sound because it:

  • Uses multiple metrics to provide a comprehensive evaluation
  • Ensures consistency and reproducibility
  • Prevents overfitting to a single metric
  • Follows established ML best practices for model selection

Final Predictions: Only the best model ({{ data.best_model_name }}) is used for generating all business insights and predictions.
