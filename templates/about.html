Project Objective

This machine learning system predicts Customer Lifetime Value (CLV) — the total amount a customer is likely to spend — using retail transaction data.

ML Prediction

Total Amount spent by customer (regression)

CLV Classification

Low / Medium / High value customer segments

Input Features

Age, Gender, Income, Purchases, Amount, Tenure, Recency, Category, Payment, Shipping

Phase-wise Methodology

  • Load and inspect retail dataset (302,010 rows, 30 columns)
  • Select relevant feature and target columns
  • Convert data types (numeric, categorical)
  • Handle missing values (drop rows with nulls)
  • Validate data (age range, negative values, categorical consistency)

  • Correlation Analysis: Pearson & Spearman correlations with target
  • Feature Selection: 16 features (6 numeric + 10 categorical): Age, Gender, Income, Total_Purchases, Amount, Tenure_months, Recency_months, Product_Category, Payment_Method, Shipping_Method, Customer_Segment, Ratings, Feedback, Month, Product_Brand, Product_Type
  • Encoding: OrdinalEncoder for categoricals (inside model pipeline)
  • Target: Total_Amount (continuous, regression task)

Train

70% of data
~211,407 rows (random, seed=42)

Validation

15% of data
~45,302 rows (model selection)

Test

15% of data
~45,302 rows (final evaluation)

Linear Regression
Baseline model with StandardScaler
Random Forest
100 trees, max_depth=8
Gradient Boosting
100 estimators, lr=0.05
Evaluation metrics: RMSE (lower = better), MAE, R² on Train, Validation, and Test sets. Best model selected by lowest Validation RMSE.

  • Models loaded at startup from pre-trained .pkl files
  • Home page: prediction form + best model result
  • About page: full analytics (model comparison, correlations, feature importance)
  • CLV classification: Low / Medium / High based on 25th and 75th percentiles
